Java File Handling
📌 Project Description
This is a simple Java File Handling project developed using Eclipse IDE.
The project demonstrates basic file operations in Java such as creating, writing, reading, appending, and copying files.

✨ Features
Create a new text file
Write data into a file
Read data from a file
Append new data to an existing file
Copy data from one file to another
Handle file-related exceptions using IOException
🛠 Technologies Used
Java
Eclipse IDE
Java I/O (java.io)
Scanner

▶️ How to Run
Open Eclipse IDE.
Import or open the project.
Open FileHandling.java.
Right-click on the Java file.
Select Run As → Java Application.
Check the output in the Eclipse Console.
💻 File Operations
The program performs the following operations:

Creates student.txt.
Writes student information into the file.
Reads and displays the file content.
Appends additional information to the file.
Creates a copy named student_copy.txt.
